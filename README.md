A make.fun entry for the bounty **"Worst Fix Ever: Funniest Commit Message"** ($2, 1st place).

## The entry

One commit message, 83 characters, for a bug fix that made everything worse:

> fix: stop users reporting bugs by removing the report button; bug reports down 100%

The fix "worked" — by the metric. The users are furious, the dashboard is green.

## How it works

`main.py` writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`
when the harness sets it). No network, no input files, no randomness — the same
line every run. `entry.txt` in this repo holds a readable copy of the same line.

## Run it

```sh
python3 main.py
```
